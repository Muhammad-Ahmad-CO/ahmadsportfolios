## Overview

A premium single-page portfolio crafted to position Muhammad Ahmed as a modern AI specialist, software engineering student, and digital problem-solver focused on automation, intelligent systems, and modern web engineering.

## Personal Brand Positioning

Muhammad Ahmed is presented as an AI-first technologist who combines automation, reasoning, and frontend engineering to solve practical business and technical challenges.

## Core Features

- Premium dark-tech aesthetic
- Responsive single-page structure
- Animated hero section
- AI-focused services and capability storytelling
- Project showcase with live demos
- Contact and social connection pathways
- Smooth scrolling and motion-driven UX

## Tech Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React
- Google Fonts

## Getting Started

```bash
git clone https://github.com/Muhammad-Ahmad-CO/ahmadsportfolios.git
cd ahmadsportfolios
npm install
npm run dev
```

## Production Build

```bash
npm run build
```

## Deployment

Suitable for Vercel, Netlify, and static production hosts.
